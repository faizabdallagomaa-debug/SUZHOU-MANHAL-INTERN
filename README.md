# SUZHOU MANHAL | سوتشو منهل

موقع شركة سوتشو منهل لتوريد الآلات وخطوط الإنتاج من الصين، بتصميم ثلاثي الأبعاد (كرة أرضية تفاعلية بمسارات التوريد من الصين إلى الشرق الأوسط).

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub (مثلاً `suzhou-manhal`).
2. ارفع محتويات هذا المجلد كما هي (`index.html` و`.nojekyll` و`README.md`) إلى جذر المستودع.
3. من المستودع: **Settings ← Pages**.
4. في **Source** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
5. بعد دقيقة أو اثنتين يظهر الرابط بالشكل:
   `https://<اسم-المستخدم>.github.io/suzhou-manhal/`

## ملاحظات

- الموقع ملف واحد (`index.html`) يحتوي كل شيء، والشعار مضمّن داخله.
- الكرة الأرضية تستخدم مكتبة Three.js من الإنترنت (cdnjs)، فتعمل تلقائياً عند الزيارة.
- GitHub Pages استضافة ثابتة بلا خادم، لذلك:
  - لوحة الإدارة والتعديل المباشر تحفظ البيانات في متصفح المدير فقط (localStorage)، ولا تظهر تعديلاته للزوار.
  - نموذج التواصل يفتح رسالة واتساب جاهزة للإرسال بدلاً من الإرسال لخادم.
